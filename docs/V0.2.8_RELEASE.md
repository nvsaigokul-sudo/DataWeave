# DataWeave v0.2.8

**Gradle:** `0.2.8` · **jpackage:** `1.2.8`

## Fixes — interactive controls

- **Home → Edit** opens Connections with the selected profile loaded (was only “Manage”).
- **Connections → New** resets the full form (host, database, SSL, timeout).
- **Delete** requires confirmation before removing a profile.
- **Windows “Start help”** toggles PostgreSQL service instructions (was a no-op button).
- **SQL → Clear** resets editor and results; **Run** disabled while a query is in flight.
- **SQL / Datasets** sync connection selection with the workspace active connection.
- **Busy guards** on Save/Test/Connect/Disconnect/Reconnect/Refresh to avoid duplicate submissions.

See [FEATURE_INVENTORY.md](./FEATURE_INVENTORY.md) and [REGRESSION_MATRIX.md](./REGRESSION_MATRIX.md).
