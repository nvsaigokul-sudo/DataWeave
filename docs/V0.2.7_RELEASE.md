# DataWeave v0.2.7

**Gradle:** `0.2.7` · **jpackage file version:** `1.2.7`

## Changelog

### Fixed (P0 — connection-first UX)

- **Home dead-end (v0.2.6 regression on laptop):** Home no longer shows only sidebar “Disconnected + Filter + Select or connect” with no obvious action. **`HomeConnectionHub`** lists saved profiles with primary **Connect**, **Retry**, **New connection**, and **Manage all**.
- **Explorer filter semantics:** Object filter is hidden until connected and metadata is loading/loaded; label is **Filter objects** (schemas/tables/columns), not a connection filter.
- **Explorer disconnected states:** Clear **Connections** / **Connect** / **Manage connection** panels when no profile is selected or profile is saved-but-not-connected; **Retry** calls Connect when not live-connected.

### Added

- **`UserPreferences.lastConnectionId`** — restores last selected profile on launch (Connect still required).
- **`UserPreferencesTest`** — desktop unit coverage for preference round-trip.

### Preserved from v0.2.5 / v0.2.6

- Connections page vertical scroll (`3c073f8`).
- Explorer lazy metadata tree, no infinite Loading (`ce83f7b`).
- Spring `startForGui` / `java.awt.headless=false` for Compose on Windows.
