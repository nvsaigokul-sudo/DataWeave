# DataWeave v0.2.6

**Gradle:** `0.2.6` · **jpackage file version:** `1.2.6`

## Changelog

### Fixed (P0)

- **Explorer infinite “Loading…” after Connect:** Root cause was treating an empty table list and swallowed `listTables` failures the same as in-flight load (`DatabaseTreeSidebar`). Replaced with lazy **database → schema → table → column** tree, explicit **Idle/Loading/Loaded/Empty/Error/Refreshing** states, **Retry**, **Refresh**, and query **timeouts** tied to connection profile.

### Added

- **`listDatabases` / `listColumns`** on `ApplicationFacade`; **`switchConnectionDatabase`** for DB switching (disconnect + profile update + reconnect).
- **`MetadataExplorerIntegrationTest`** (Zonky embedded PostgreSQL): discovery, disconnect/reconnect, refresh, DB switch, not-connected errors.
- **Startup timing:** `StartupTiming` + `launch.log` line `DesktopSession ready in …ms (spring-ready=…ms)`.

### UI (Compose Desktop)

- Design tokens (`DesignTokens.kt`), typography refresh, explorer toolbar (filter, refresh, icons), Connections **Advanced** section (SSL, timeout, JDBC preview). Connections vertical scroll fix from v0.2.5 preserved.
