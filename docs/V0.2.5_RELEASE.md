# DataWeave v0.2.5

**Gradle:** `0.2.5` · **jpackage file version:** `1.2.5` (derived from Gradle via `jpackageVersion()`)

## Changelog

### Fixed

- **Connections page scroll:** The connection form and saved profiles scroll vertically when content exceeds the workspace center pane (`ConnectionsScreen` + `WorkspaceShell.fillMaxSize`). Replaces nested `LazyColumn` that blocked scrolling. Commit `3c073f8`.

### Unchanged from v0.2.4

- PostgreSQL connection sessions (Save/Test/Connect/Disconnect/Reconnect).
- Modern workspace UI, table browse, datasets, CSV export.
- **`startForGui()` / Spring `headless(false)`** for Compose on Windows (`SpringHeadlessPropertyTest`).
