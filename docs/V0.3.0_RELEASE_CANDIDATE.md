## Owner acceptance checklist (Windows packaged app)

1. Install latest RC MSI from CI artifact after you authorize a release build (or build locally from this branch).
2. Launch — confirm no `HeadlessException`; Settings → System/Light/Dark persists across restart.
3. Connections: scroll form, save password, restart app, connect (credential recovery if needed).
4. Explorer: databases → schemas → tables; no infinite Loading; Retry on forced failure.
5. Data: open real table; sort/filter/page; row numbers; NULL vs empty; export CSV.
6. Datasets: load FK suggestions; pick join type; preview; save definition; reopen app.
7. SQL: SELECT runs; INSERT/UPDATE rejected; history recorded.
8. Projects: create, rename, duplicate, delete.
9. Exit — no hung connections.
