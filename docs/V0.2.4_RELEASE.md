# DataWeave v0.2.4

**Gradle:** `0.2.4` · **jpackage file version:** `1.2.4`

## Highlights

- **PostgreSQL connection sessions:** Save profile without opening a live pool; explicit **Test**, **Connect**, **Disconnect**, **Reconnect**; bad credentials and unreachable hosts surface **Error** without a cached pool (`ConnectionLifecycleIntegrationTest`).
- **Modern workspace UI:** Top bar, database tree sidebar, connection status, light/dark theme persistence, status bar (`WorkspaceShell`, `DatabaseTreeSidebar`).
- **Table browse:** Server-side filter/sort, cell copy, streamed CSV export (no silent 100k row cap).
- **Datasets:** Output column map persist (Flyway V3), CSV register vs preview flows.
- **Preserved:** `startForGui()` / Spring `headless(false)` for Compose on Windows (`SpringHeadlessPropertyTest`).
