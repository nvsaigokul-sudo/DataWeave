# DataWeave v0.3.0 — release notes (draft)

**Product version:** `0.3.0`  
**Native package version (Windows/Linux/macOS jpackage):** `1.3.0`  
**Baseline:** v0.2.9 @ `3dbb41c`

See [VERSIONING.md](./VERSIONING.md) for why installers show **1.3.0** while the GitHub release is **v0.3.0**.

## Highlights

- **Visual Dataset Builder:** Canvas layout, join edges, join-key pickers, graph validation, preview with stale-on-error, persisted `definition_json`.
- **Projects:** Linked datasets and queries, drag reorder, unsaved-changes dialog, Open in Datasets / Open in SQL.
- **Data grid:** Spreadsheet selection (shift-rectangle, row/column), Ctrl+C (TSV), Ctrl+Shift+C (CSV), paging and filters.
- **Explorer:** Expandable Columns, Primary keys, Foreign keys, and Indexes sections per table.
- **SQL:** Read-only enforcement (`BEGIN READ ONLY`), non-SELECT rejected before run.
- **Settings:** Light / Dark / System theme with persistence.
- **Schema:** Flyway **V5** `project_items` for project links and ordering.

## Install

Download **DataWeave v0.3.0** from GitHub Releases when published:

| OS | Files |
|----|-------|
| Windows | `windows-DataWeave-Setup.msi` (from CI), `DataWeave-1.3.0.exe` |
| Linux | `.deb`, AppImage (`dataweave_1.3.0_*`) |
| macOS | `.dmg` / `.pkg` (Apple Silicon from CI matrix) |

Verify with `SHA256SUMS.txt` on the release page.

## Upgrade from v0.2.9

- Install over existing 1.2.9 MSI (same upgrade UUID) or uninstall first.
- Local SQLite metadata migrates forward automatically (V1–V5); backup runs before migrate.

## Known limitations

See [KNOWN_LIMITATIONS.md](./KNOWN_LIMITATIONS.md). Read-only product scope unchanged: no cross-database joins, no cloud sync, no arbitrary write SQL.
