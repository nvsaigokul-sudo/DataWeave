# DataWeave v0.3.0

**Product version:** `0.3.0` · **Native installer package version:** `1.3.0` (see [VERSIONING.md](https://github.com/nvsaigokul-sudo/DataWeave/blob/main/docs/VERSIONING.md))

## Highlights

- **Visual Dataset Builder:** Canvas layout, join edges, join-key pickers, graph validation, preview with stale-on-error, persisted `definition_json`.
- **Projects:** Linked datasets and queries, reorder, unsaved-changes dialog, Open in Datasets / Open in SQL.
- **Data grid:** Spreadsheet selection, Ctrl+C (TSV), Ctrl+Shift+C (CSV), paging and column filters.
- **Explorer:** Expandable Columns, Primary keys, Foreign keys, and Indexes per table.
- **SQL:** Read-only enforcement (`BEGIN READ ONLY`); non-SELECT rejected before run.
- **Settings:** Light / Dark / System theme with persistence.
- **Metadata:** Flyway **V5** `project_items` for project links and ordering.

## Install

| OS | Files on this release |
|----|------------------------|
| Windows | `windows-DataWeave-Setup.msi` (CI-built MSI), `windows-DataWeave-1.3.0.exe` |
| Linux | `linux-*.AppImage`, `linux-dataweave_1.3.0_amd64.deb` |
| macOS (Apple Silicon) | `macos-arm64-*.dmg`, `macos-arm64-*.pkg` |

Verify downloads with **`SHA256SUMS.txt`**.

## Upgrade from v0.2.9

Install the new MSI over 1.2.9 (same upgrade UUID) or uninstall first. SQLite app metadata migrates V1–V5 with pre-migrate backup.

## Verification (automated)

- Linux: `./gradlew test :desktop:runHeadlessSmoke` on release tag.
- Windows: packaged install + `windows-packaged-smoke.ps1` (diagnose, headless-smoke, gui-smoke) on `windows-latest`.

## Known limitations

- Read-only scope unchanged (no cross-database joins, cloud sync, or arbitrary write SQL).
- **Owner manual Windows checklist** (PostgreSQL E2E, full grid/DnD/projects flows): see [WINDOWS_RELEASE_ACCEPTANCE.md](https://github.com/nvsaigokul-sudo/DataWeave/blob/main/docs/WINDOWS_RELEASE_ACCEPTANCE.md) — recommended after install.
- **Windows PRD performance baselines** not measured in CI; see [PERFORMANCE_BASELINE.md](https://github.com/nvsaigokul-sudo/DataWeave/blob/main/docs/PERFORMANCE_BASELINE.md).
