# DataWeave downloads

Installers are **not** stored in this Git folder (to keep the repository small).

## Get the latest version

**[Download from GitHub Releases](https://github.com/nvsaigokul-sudo/DataWeave/releases/latest)**

| Operating system | What to download |
|------------------|------------------|
| Windows | `.msi` (recommended) or `.exe` |
| Linux | `.AppImage` or `.deb` |
| macOS (Apple Silicon) | `.dmg` or `.pkg` from the **macos-arm64** assets |
| macOS (Intel) | `.dmg` or `.pkg` from the **macos-x64** assets |

After downloading, verify checksums using `SHA256SUMS.txt` on the release page.
